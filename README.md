## MermaidViewerNpp

This is a Mermaid format viewer for Notepad++.  
Within Markdown documentation, code blocks designated with ```mermaid and written in Mermaid format are also permitted.

  
### Install
- Right‑click the downloaded ZIP file and select "Properties".  
In the "General" tab, locate the "Security" section and check the "Unblock" option to allow the file to be used.
- Please extract the files and place them in the following folder:  
  C:\Program Files\Notepad++\plugins\MermaidViewer
- For the 64-bit version only.
